# GAN Digit Generator (demo)

Runs the trained DCGAN and MLP-GAN generators from Experiment 13 in the browser.

## Run in VS Code
1. File > Open Folder > `gan_digit_demo`
2. Right-click `index.html` > **Open with Live Server** (install the "Live Server" extension), or in the VS Code terminal run: `python -m http.server 8000` and open http://localhost:8000
3. Click **Generate**. Use the slider to morph.

No installs or internet needed. Files: `index.html` (page), `gan.js` (generator code), `weights.js` (trained weights).

## Run online (GitHub Pages)
After uploading this repo to GitHub: Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save. The demo opens at https://YOUR-USERNAME.github.io/gan-digit-demo/
